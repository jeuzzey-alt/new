# Дайджест: психиатрия и психотерапия

Каждое утро (07:55 по Москве) GitHub Actions запускает `digest.py`:

1. ищет в **PubMed** новые статьи по психиатрии и психотерапии (MeSH + заголовок/аннотация);
2. добавляет **препринты** (medRxiv, bioRxiv, PsyArXiv и др.) из Europe PMC;
3. убирает дубликаты и уже отправленные статьи (база `seen.sqlite3` хранится в репозитории);
4. отправляет письмо с заголовками, ссылками и полными аннотациями через SMTP Яндекса.

## Настройка (один раз)

Settings → Secrets and variables → Actions → **New repository secret**:

| Секрет | Значение |
|---|---|
| `SMTP_USER` | ваш адрес в Яндекс Почте (с него уходит письмо и на него же приходит) |
| `SMTP_PASSWORD` | пароль приложения Яндекса (id.yandex.ru → Безопасность → Пароли приложений → Почта) |
| `MAIL_TO` | *(необязательно)* другой адрес получателя |
| `NCBI_API_KEY` | *(необязательно)* ключ NCBI для более высоких лимитов |

Проверка: вкладка **Actions** → «Дайджест психиатрии» → **Run workflow**.

## Изменить запрос

Поисковые строки — переменные `PUBMED_QUERY` и `EPMC_QUERY` в начале `digest.py`.
Время — строка `cron` в `.github/workflows/digest.yml` (указывается в UTC: Москва − 3 часа).
